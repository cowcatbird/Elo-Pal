# Changelog

## 1.8.0 — Initial public release

### Game review

- Bundled Stockfish.js 19.0.1 Lite WebAssembly analysis, with no account or analysis service required.
- Manual PGN/FEN import, local PGN files, and one-click import from Chess.com and supported Lichess pages.
- Game summaries with custom accuracy estimates, evaluation graphs, and move-quality totals.
- Book, Brilliant, Great, Best, Excellent, Good, Inaccuracy, Mistake, Blunder, and Forced classifications.
- Opening identification and variations from 3,865 named lines covering all 500 ECO codes.
- Engine-line walkthroughs, legal board exploration, and return-to-game navigation.

### Coach and interface

- Position-specific Coach Cat advice about detected threats, exchanges, forks, pins, piece activity, and legal continuations.
- Advice follows the displayed position while explanations of played-move grades retain their original review evidence.
- Large board with bundled Cburnett pieces, readable move icons, compact opening details, and visible move playback controls.
- A/D and arrow-key navigation, Home/End, board-flip and sound shortcuts.
- Local sound effects for ordinary moves, captures, castling, checks, promotions, and checkmate.
- Evaluation bar retains its last known score while the next position is being analyzed.
- Lowercase cowcatbird branding and the pink Coach Cat portrait.

### Public project

- Installation and development documentation, contribution guide, privacy information, and security reporting guidance.
- Bundled third-party licenses, source provenance, automated tests, and a reproducible extension ZIP packaging script.
- GitHub issue templates and automated checks and release packaging.

Earlier development builds were private. This changelog starts with the public 1.8.0 release rather than reconstructing an unverified release history.
